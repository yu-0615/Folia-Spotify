# 簡轉繁（zh-hant-lyrics）

歌词进播放页之前（`lyrics.transform`），把简体的歌词原文与翻译换成繁体。纯 client，不需要权限，不存数据。

- **转成**：台湾字形（默认）、台湾字形与用语（「鼠标」→「滑鼠」、「软件」→「軟體」）、香港字形。
- **转换歌词原文 / 转换翻译**：两个开关，默认都开。改了设置，正在显示的歌词马上重转。
- 逐字时间、音节和保存过的分词照旧对得上：一行先整串转，长度没变就按原来的长度切回去；台湾用语改了长度时各段分开转，
  对不上整行的分词交给宿主丢掉。
- 日文歌（有汉字或假名的行里，四分之一以上带假名）的原文不转，免得把日文汉字写成繁体；它的中文翻译照样转。中文歌里夹的一两句日文也不转，其余照转。罗马音不碰。

转换用 [opencc-js](https://github.com/nk2028/opencc-js) 1.4.2 的 `cn2t` ESM 构建，原样放在 `vendor/`（MIT，词典数据 Apache-2.0，许可证在同一目录）。
每种字形的词典第一次用到时建一次，约一秒。

## 安装

这个目录**没有签名**，开发版也不会自动扫描 `dev/folium/`：

1. 「设置 → 模组」打开「模组系统」。
2. 模组面板右上角「打开模组目录」，把 `zh-hant-lyrics` 整个目录复制进去（或者打成 zip 拖到模组面板上），点「重载」。
3. 打开「簡轉繁」那一行的开关并确认（显示为「未验证」）。展开那一行可以换字形、开关原文与翻译的转换。

不要放进仓库的 `mods/`：那里的模组必须带官方签名，`test/unit/mod-system/sampleMods.test.ts` 会失败。
